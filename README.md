# Ain't Another Developer (AAD)

Agentic Integration Factory (AIF)

Laboratorio de ingeniería agéntica para generar,
probar y publicar integraciones a partir de
requerimientos funcionales.

## Stack inicial
- Ubuntu Server
- Docker Compose
- PostgreSQL
- Bank Sample Database

## Objetivo MVP
Requerimiento → Análisis → Desarrollo →
Pruebas → Contenedor → Publicación
